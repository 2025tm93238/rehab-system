# AI Usage Log

## Tool Used

The primary AI tool used in this project was **Claude**. It was used as a coding assistant to support development, debugging, and documentation.

---

## How AI Was Used

Claude was used to:

* Generate initial backend code (Node.js, Express APIs)
* Assist in implementing JWT authentication and middleware
* Suggest API structures and request/response formats
* Help debug errors during development
* Provide guidance for frontend components and integration
* Assist in writing documentation

---

## Example Prompts

* “Generate Express CRUD APIs for patient management”
* “Create JWT authentication middleware in Node.js”
* “Fix error in Express controller”
* “Design REST API for therapy session tracking”
* “Create PostgreSQL schema for patient, session, and progress tables”
* “Write API validation rules for request body in Express”
* “Connect React frontend with backend APIs using Axios”
* “Handle token-based authentication in React app”
* “Debug 401 unauthorized error in API requests”

---

## AI vs Manual Work

* AI generated base code and suggestions
* Manual work included:

  * Adding validations
  * Debugging errors
  * Integrating frontend and backend
  * Structuring microservices

**Example:**
The JWT authentication code generated by AI was modified to include role-based access control and improved error handling before integration.

---

## Workflow

1. Define requirement
2. Use Claude to generate initial code
3. Review and modify
4. Test and debug
5. Integrate into project

AI-assisted development was combined with incremental Git commits to maintain clear version history and track progress.

---

## Summary

Claude helped accelerate development and provided useful guidance. All generated code was reviewed and adapted manually, ensuring proper understanding and functionality.
