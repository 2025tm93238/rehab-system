# AI Reflection Report

## Introduction

During the development of the Rehab Patient Tracking System, AI tools (primarily Claude) were used as a supporting assistant for coding, debugging, and design guidance. This report reflects on how AI contributed to the development process and overall learning experience.

---

## Did AI Help or Hinder Understanding?

AI played a valuable role in accelerating development, particularly for generating initial code and guiding implementation. It helped quickly set up APIs, authentication logic, and basic frontend structures.

At the same time, understanding the generated code was essential. In several cases, AI outputs required review and modification, which ensured that the concepts were properly understood rather than used blindly. Overall, AI supported learning while still requiring active involvement.

---

## Issues Faced While Using AI

Some challenges were encountered while working with AI-generated outputs:

* Certain code snippets had logical or syntax issues
* API structures did not always align with the intended microservices design
* Debugging was required for authentication and request handling issues

**Example:**
An issue was encountered where JWT tokens were not being validated correctly across services. This required debugging middleware and verifying request headers to resolve the problem.

---

## Learning from Debugging AI-Generated Code

Debugging AI-generated code provided valuable learning opportunities:

* Improved understanding of JWT authentication and middleware flow
* Better clarity on how backend APIs interact with the database
* Experience in identifying and fixing integration issues between frontend and backend
* Strengthened problem-solving and debugging skills

This process helped in building confidence in handling real-world development issues.

---

## Comparison: AI-Assisted vs Manual Development

* **AI-assisted development** improved speed and provided direction for common tasks such as CRUD APIs and authentication
* **Manual development** ensured correctness, customization, and deeper understanding of the system

A combination of both approaches resulted in a balanced and effective development workflow.

---

## Conclusion

AI acted as a valuable assistant throughout the project by accelerating development and providing guidance. At the same time, manual effort was essential for debugging, integration, and ensuring correctness. This experience demonstrated how AI can be effectively used as a support tool while maintaining full understanding and control over the system.
