# Frontend

React single-page application for the Rehab Patient Tracking System.

- Tooling: Vite + React + React Router + Axios
- Dev port: `5173`
- Talks to the API Gateway at `http://localhost:4000`

## Pages (planned)

- `/login`, `/signup` — authentication
- `/dashboard` — overview stats
- `/patients` — list, search, register, edit patients
- `/patients/:id` — patient detail with sessions and progress timeline
- `/sessions` — therapy sessions calendar / list
- `/sessions/:id` — session detail and progress entry

Implementation pending.
